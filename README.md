# شجرة العائلة — Family Tree 2D

شجرة عائلة عربية تعمل في المتصفح. كل شيء يُحفظ في جهازك، لا خادم ولا حساب.

**جرّبها:** https://abudayyehabood.github.io/family-tree-2d/

## ماذا تعمل

- ابدأ بالجد الأكبر، ثم أضف الأبناء والبنات بالضغط على أي اسم.
- **زوجة ثانية وثالثة وأكثر**: اضغط على الرجل، اختر «زوجة»، ثم «إضافة زوجة أخرى».
- الابن الذي تضيفه وأنت على زوجة يُعلَّق على فرع الأب، وتُسجَّل أمه وتظهر في بطاقته.
- **تكبير**: العجلة أو القرص بإصبعين، أزرار + و −، ضغطة مزدوجة على أي اسم تكبّر عليه، وزر «تكبير المحدد». حتى ١٦ ضعفًا.
- طباعة، وحفظ الشجرة صورة PNG أو ملف SVG.
- الأسماء تُحفظ تلقائيًا في المتصفح (localStorage). لا تغادر جهازك.

## التشغيل محليًا

```bash
npm install
npm run dev        # خادم التطوير
npm run onefile    # ملف HTML واحد: شجرة-العائلة.html
npm run pages      # نفس الملف، ويحدّث docs/index.html للنشر
```

React + Vite. البناء ينتج صفحة واحدة مستقلة بلا أي طلبات خارجية.
